# Wallpapers

Bundled wallpapers used by the Hyprland configuration:

- `Uzumaki.png`
- `a_mountain_range_with_snow.png`
- `atmosphere.jpg`
- `central.png`
- `china-mountains.png`
- `joy_division.jpg`
- `mountains.png`
- `pole.jpg`
- `punpun2.png`
- `street.jpg`

`2026-10-30_10-45.png` is intentionally excluded because it is a screenshot,
not a wallpaper.

`hyprlock.conf` uses `mountains.png` as the lock screen background.

`install.sh` copies these images to `~/.config/hypr/wallpapers`. Add your own
images there and run `~/.config/hypr/wallpaper-restart.sh` to apply one.
